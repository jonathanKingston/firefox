MHTML CID Support Test

What This Tests

This HTML file tests whether Firefox can correctly handle Chrome-generated MHTML files that use Content-ID headers and cid: URI references instead of Content-Location headers.

Chrome's MHTML Format

Chrome/Blink uses Content-ID headers for subresources:

Content-Type: text/css
Content-ID: <css-b8ff2cbc-0368-45e5-a43d-c712d631fc8e@mhtml.blink>
Content-Transfer-Encoding: quoted-printable

And references them using cid: URIs:

<link rel="stylesheet" href="cid:css-b8ff2cbc-0368-45e5-a43d-c712d631fc8e@mhtml.blink">

Firefox's MHTML Format

Firefox uses Content-Location headers:

Content-Type: text/css
Content-Location: https://example.com/style.css

And references them using normal URLs:

<link rel="stylesheet" href="https://example.com/style.css">

✓ CID Support Implemented

Firefox now supports both formats when reading MHTML files:

  • Content-Location → URL references (Firefox export)
  • Content-ID → cid: references (Chrome export)

This ensures maximum compatibility across browsers!

Manual Test Instructions

  1. Save this page as MHTML in Chrome (Save As → Web Page, Single File)
  2. Open the saved .mhtml file in Firefox
  3. Verify that:
    • All CSS styles are applied correctly
    • The blue test box above has proper styling
    • No network requests are made (check DevTools)

If you can see a green square with "TEST" text above, embedded resources are working!
